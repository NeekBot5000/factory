# Timber for Roblox

The Roblox version of Timber, written in Luau and synced into Roblox Studio with [Rojo](https://rojo.space/).
It plays the Godot game the Godot way: the same world, meshes, numbers, HUD and sounds, exported from the Godot
project. The plan, and the decisions behind this code, are in [`../docs/roblox-port.md`](../docs/roblox-port.md).
What's still different from the Godot game is listed in [`../docs/roblox-style.md`](../docs/roblox-style.md).

- `src/shared/` - game data and logic both sides use:
  - Config, the tools and items;
  - `GodotWorld` and `GodotBuilds` (generated by `tools/ExportRobloxWorld.gd`);
  - Builds, Land, Mining, Rail, Drones and Weight.
- `src/server/Services/` - the server, which decides everything:
  - saves (DataService);
  - money and the trucks (EconomyService);
  - trees, logs and saplings (TreeService, LogService, SaplingService);
  - carrying, vacuums and the blower (CarryService, VacuumService);
  - land and building (LandService, BuildService, BuildBehaviors);
  - power, wires, logic and sensors (CircuitService);
  - production machines (ProductionService);
  - logistics and the tree farm, including the feller, drill rig, charger and rotator (FactoryService);
  - rails and minecarts (RailService);
  - drones (DroneService);
  - mining and dynamite (MiningService);
  - the rake and watering can (HelperService);
  - trophies (TrophyService);
  - the delivery van (DeliveryService);
  - the Godot meshes (WorldMeshes).
- `src/client/` - the client:
  - input, moving and the first-person arm;
  - hints, the build menu and hologram;
  - the HUD, shop and title screen;
  - effects.
- `models/` - every machine, decoration and tool from the Godot game as .glb (import with File > Import 3D).
  Re-export them with `godot --headless --path . res://tools/ExportModels.tscn` from the repo root.

**Setting up for the first time: follow [SETUP.md](SETUP.md).**
Run it: `rojo serve` here, then connect from the Rojo plugin in Studio.

## Tests
CI runs all of these on every push. From the repo root:
- `luau tests/run.luau` (from `roblox/`) - the pure logic
- `rojo build -o Timber.rbxl roblox`, then:
  - `lune run roblox/tests/lune/playtest.luau Timber.rbxl` - the whole game through the real server scripts
  - `lune run roblox/tests/lune/client.luau Timber.rbxl` - the client scripts
  - `lune run roblox/tests/lune/sync.luau Timber.rbxl` - the Studio Live Sync plugin builds what Rojo builds

The tools are on GitHub: Luau (luau-lang/luau), Rojo 7.7.1 and Lune 0.10.4.
`tools/roblox_view.sh` renders the Godot game and the Roblox build side by side from the same cameras.
